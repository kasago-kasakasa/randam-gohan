利用規約・プライバシーポリシー

制定日：2026年11月24日　運営：kasago-kasakasa（個人開発）

要点：このアプリは広告や行動の追跡を行いません。ログインした場合だけ、あなたの冷蔵庫の記録などを Google のサービス（Firebase）に保存します。データはいつでも自分で削除できます。

1. このアプリについて

「ランダムごはん」（以下「本アプリ」）は、献立をランダムに提案し、冷蔵庫の中身を記録できる無料のWebアプリです。個人が趣味で開発・運営しています。本アプリを使った時点で、この利用規約・プライバシーポリシー（以下「本ポリシー」）に同意したものとみなします。

2. 取り扱う情報

ログインしない場合

  • 冷蔵庫の記録、お気に入り、保存した献立、履歴、設定は、お使いの端末のブラウザの中だけに保存されます。運営者には送られません。

Googleアカウントでログインした場合

  • Googleアカウントのメールアドレス、表示名、ユーザーID（Googleが発行する識別番号）
  • 本アプリに入力・保存した内容（冷蔵庫の記録、お気に入り、保存した献立、履歴、設定、除外したい食材など）

パスワードは本アプリでは扱いません（ログインは Google の画面で行われます）。位置情報、連絡先、写真などは取得しません。

3. 利用目的

  • ログインした本人が、複数の端末で同じデータを使えるようにするため
  • 不正な利用を防ぎ、障害に対応するため

上記以外の目的には使いません。広告配信、販売、マーケティングには使いません。

4. 外部サービスと保存場所

本アプリは次の外部サービスを利用しています。これらのサービスは、各社の規約とプライバシーポリシーに従って情報を取り扱います。

  • Firebase（Google LLC）：ログインとデータの保存。データは Google のサーバー（日本国外の場合があります）に保存されます。　Firebase のプライバシーと安全性
  • GitHub Pages（GitHub, Inc.）：アプリのファイルの配信。アクセス時に IPアドレス等が GitHub に記録される場合があります。　GitHub のプライバシーに関する声明
  • Google Fonts（Google LLC）：文字の表示。アクセス時に IPアドレス等が Google に送られる場合があります。　Google プライバシーポリシー

アクセス解析ツールや広告は使用していません。

5. 第三者への提供

法令に基づく場合を除き、あなたの情報を本人の同意なく第三者に提供しません。なお、前項の外部サービスに保存・処理を委ねることは、本アプリを動かすために必要な範囲に限られます。

6. 安全管理

保存されたデータは、本人のアカウントでログインしたときだけ読み書きできるよう、アクセス制限をかけています。運営者は、障害対応など必要な場合を除き、個々のデータを閲覧しません。ただし、インターネット上のサービスである以上、完全な安全を保証するものではありません。

7. データの確認・削除

  • 端末のデータ：設定の「すべてのデータを初期化」で削除できます。ブラウザのサイトデータを消しても削除されます。
  • クラウドのデータ：ログイン中に、設定の「クラウドのデータを削除」で、運営者を介さずに完全に削除できます。
  • ログアウト：ログアウトすると、その端末からデータが消えます（クラウドには残ります）。
  • Googleアカウントと本アプリの連携は、Googleアカウントの「サードパーティ製のアプリとサービス」から解除できます。

8. 免責事項

  • 料理名・材料・作り方・栄養価・調理時間は、一般的な家庭料理をもとにした目安です。栄養価は日本食品標準成分表などを参考にした概算で、正確さを保証するものではありません。
  • 本アプリは医療・栄養指導を目的としたものではありません。持病、食事制限、妊娠中などで食事に配慮が必要な方は、医師や管理栄養士にご相談ください。
  • アレルギーについて：「除外したい食材」は料理名と材料名の文字で判定する簡易な機能で、アレルギー対策として十分ではありません。使う食品の原材料表示を必ずご自身で確認してください。
  • 調理の際は、食材の鮮度・加熱・衛生に十分注意してください。冷蔵庫の記録は中身の有無だけを扱い、量や消費期限は管理しません。
  • 通信環境や外部サービスの状態により、データの同期・保存ができない場合があります。大切なデータは、設定の「データをコピー」で控えを取ることをおすすめします。
  • 本アプリは無料で提供しており、予告なく内容の変更・中断・終了をすることがあります。
  • 本アプリの利用によって生じた損害について、運営者は、運営者の故意または重大な過失による場合を除き、責任を負いません。

9. 禁止事項

  • 本アプリやサーバーに過度な負荷をかける行為、不正アクセス、他人のアカウントの利用
  • 法令または公序良俗に反する行為

10. 本ポリシーの変更

本ポリシーは必要に応じて変更することがあります。変更した場合は、このページの内容と制定日（改定日）を更新します。
